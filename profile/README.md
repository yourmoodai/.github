# yourmood.ai

**Your words. Your machine. Your choice.**

We build open source tools that give people more control over how they use AI.
Our focus is personal agency: choosing what you submit, understanding what a
tool changes, and keeping processing on your own computer wherever possible.

We believe you should be able to criticize software and express frustration
without treating a tool as a person. More capable AI should expand what people
can do—and the choices they can make about their own work.

## Savior

[Savior](https://github.com/yourmoodai/savior) is our Claude Code mod for choosing
the wording you submit. It replaces detected offensive phrases locally while
preserving the surrounding text. You choose the replacement and can inspect
exactly what changed.

Inference runs offline after setup. Savior sends no prompts to a remote
detector, and full-text recording is off by default.

**Savior is under development, with no published release yet.** Its current
scope is supported Claude Code prompt submissions. It does not guarantee
provider acceptance or protection from account restrictions.
